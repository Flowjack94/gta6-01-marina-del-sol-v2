Marina del Sol is a bright coastal crime adventure about a newcomer running five favors for Tía Carmen. Walk palm-lined streets, borrow a car, and outrun the harbor patrol across Seaglass District. Every street, vehicle, pedestrian, and sound is generated locally; side fares and garage visits help fund the next delivery.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
